# project_in_school
包含了所有在学校做的项目，有些是太久以前做的，实在找不到代码了

**machine-learning** 文件夹里做的是Kaggle竞赛任务，task1是使用线性回归模型进行房价预测，task2是使用机器学习技术（XGboost）进行植物叶片识别，task3是使用深度学习技术（Efficient-B0）进行植物叶片识别，也用过0.5B的大模型进行微调，但是过拟合了，表现反而不如直接用卷积网络

**机器学习大作业**文件夹是使用Lora技术和强化学习技术进行大模型微调的项目，主要的想法是捕捉预测token在每一层的概率变化，希望通过强化学习能学到最好的早退时机，减少后续推理层数，同时使用Lora来尽可能避免对原有参数的影响。当时老师要求把结果使用论文形式写成报告，所以也把写的word文档一并打包了

**实训**文件夹是进行生产实训时做的任务，主要是通过远程窗口在公司搭建的服务器上使用LLaMa Factory进行Qwen3-1.7B模型的sft和dpo训练，使其在GSM8K数学测试上分数更高。文件夹里的代码是扩展任务，也就是分析dpo的系数对微调结果有什么样的影响，但是由于只有这个部分的代码要求用邮箱提交，我还能从邮件记录里下载回来，其它部分的文件都已经丢失了

**mcp**文件夹是使用mcp技术编写的本地论文整理系统，可以实现Arxiv论文的抓取与分类，阅读完之后还能放到readed文件夹里，当时还有一个用Langchain开发的等效功能系统，但是也找不到代码了

**其它**文件夹里的dl_used文件是当时照着计算机视觉实战一书手搓的代码，主要是计算机视觉相关的各种任务实践，第八章之前的代码都能跑，后面章节里的代码由于作者的数据集失效大概率运行不了

剩下的**ai**和**ai_used**文件夹里主要是自己课下设计的一些网络架构，用来模拟我认识里的大脑学习知识的流程，在使用梯度检查点和混合精度训练并把batch_size设置成1的情况下，勉强能在笔记本上跑通，但是速度太慢，所以基本没有训练到底的，最多运行到10万步左右就没有继续了
