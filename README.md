# project_in_school
包含了所有在学校做的项目，有些是太久以前做的，找不到代码了，具体看README文件

**machine-learning**文件夹里是做的Kaggle竞赛任务，task1是使用线性回归模型进行房价预测，task2是使用机器学习技术进行植物叶片识别，task3是使用深度学习技术进行植物叶片识别
**机器学习大作业**文件夹是使用Lora技术和强化学习技术进行大模型微调的项目，当时老师要求把结果使用论文形式写成报告，所以也把写的word文档一并打包了
**实训**文件夹是进行生产实训时做的任务，主要是通过远程窗口在公司搭建的服务器上使用LLaMa Factory进行Qwen3-1.7B模型的sft和dpo训练，文件夹里的代码是扩展任务，也就是分析dpo的系数对微调结果有什么样的影响，但是由于只有这个部分的代码要求用邮箱提交，我还能从邮件记录里下载回来，其它部分的文件都已经找不到了
**mcp**文件夹是使用mcp技术编写的本地论文整理系统，当时还有一个用Langchain开发的等效功能系统，但是也找不到代码了
**其它**文件夹里的dl_used文件是当时照着计算机视觉实战一书手搓的代码，第八章之前的代码都能跑，后面的章节里由于大部分数据集失效基本都运行不了。剩下的**ai**和**ai_used**文件夹里主要是自己设计的一些网络架构，用来搭建我认为的大脑学习知识的流程，在使用梯度检查点和混合精度训练并把batch_size设置成1的情况下，勉强能在笔记本上跑通，但是速度太慢，所以基本没有训练到底的，基本都是运行到10万步左右就停了
